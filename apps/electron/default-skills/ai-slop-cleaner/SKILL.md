# AI Slop Cleaner — 清理 AI 腔

检测并清除 AI 生成文本的机器味：套话、机械结构、夸张标记，改写为自然的人类表达（保留语义、事实、术语）。也提供"AI 相似度"诊断。

> 参考：tuwulalo/ai-slop-cleaner-en-ru（Claude skill，MIT），按 MyYoda 流程适配并内置常见标记清单。

## 核心原则：单看一个词不是证据

人类也会写"值得注意的是"或用长破折号。AI 的特征是**密度 + 同质化 + 无人类噪音**：
- **密度**：每千字命中多少类 AI 标记
- **共现**：AI 标记成群出现（"不只是 X 更是 Y" + 三连排比 + 空泛结尾）
- **同质化**：句长节奏过于均匀、格式完美、零错字、零个人化
- **无人类噪音**：没有口误、俚语、个人细节、对话感

诊断永远是**概率性**的：不要断言"这是 AI 写的"，而是"根据这些特征像 AI 输出"。

## 常见 AI 标记清单（内置）

| 类别 | 例子 |
|---|---|
| 套话开头 | "值得注意的是"、"值得一提的是"、"首先/其次/最后"滥用 |
| 机械句式 | "它不只是 X，更是 Y"、"在当今……的背景下" |
| 排比三连 | 同一句式连续三次（规则三） |
| 夸张强调 | emoji 滥用（🚀💡✅ 当装饰）、加粗滥用（**每个**关键句） |
| 空泛总结 | "综上所述"、"总之，我们可以说"（无实质信息） |
| 虚词填充 | "deep dive"、"under the hood"、"delve" 等流行 AI 词 |
| 过度礼貌 | "希望这有帮助！"、"如果您有任何问题"（非用户要求的场合） |

## 流程

### 1. 读全文 + 判断语域
先确定文本语域（正式 / 技术博客 / 论坛 / 即时消息），**在语域内改写**：
- 正式文档里不放俚语
- 闲聊里不放官腔

### 2. 标记定位（诊断模式）
逐条列出命中：精确引用原文 + 命中类别 + 置信度。
给出整体判定：**AI 相似度评级**（低/中/高 + 依据），始终概率表述。

### 3. 清理（改写模式）
- 逐条重写：套话 → 直说；排比 → 拆开；强调 → 删冗余
- 保留：事实、术语、代码、引用、用户原意
- 输出清理后全文（可附带改动摘要：改了哪几类、多少处）

### 4. 默认顺序
先诊断，再问是否清理；用户明确说"清理/改写"则直接进入清理模式。

## 原则

- **永不篡改事实/术语/引用**
- 判断概率化，不宣称"作者是谁"
- 代码/配置文件不是本 skill 的目标（那是 code-review 的范围）
- 长文档先分段处理，保持上下文
