# MyYoda v0.10.12 更新

## Improvements（体验改进）

- **新增「编码优化」设置标签**：Coding 加强 / Graphify 环境 / CodeClaw / Git-PR 标识等设置从通用设置移入独立的「编码优化」标签页，通用设置只保留思考深度等通用行为项
- **磁盘管理升级为可行动清理面板**：磁盘占用详情展示 Top 10 大文件（含标题/大小/归档状态/更新时间）与孤儿残留数据；归档清理新增「立即清理」按钮（先预览可释放量再确认执行，不必等下次启动）；存量会话中的超大内嵌图片可一键剥离回收空间
- **受管浏览器地址栏支持直接搜索**：`BrowserNavigate` 和浏览器面板地址栏现在可以直接输入搜索词——明确的网址、裸域名、localhost 和 IP 地址仍直达打开，普通文字自动用 Google 搜索；支持导航到 `about:blank` 打开空白页
- **精简渠道命名**：Kimi API 渠道标签简化为「Kimi API」；通义千问渠道合并为单一「通义千问」入口（原 OpenAI 协议旧版渠道仍可正常使用，仅不在新建下拉中展示）
- **火山引擎渠道体系重整**：新增「火山引擎 API」独立渠道；原「豆包」渠道更名为「火山方舟 Coding Plan」，「火山方舟 Coding Plan」（订阅制）更名为「火山方舟 Agent Plan」，配套图标统一替换为火山引擎新版本；存量渠道会自动完成命名迁移，无需手动调整
- **左侧栏功能组恢复纯手动收起**：点击「功能」组内的二级目录（计划/看板/画布/插件/消息/知识库）保持展开并显示全部项（仅高亮激活项），收起只由手动点击「功能」头部触发

## Performance（性能优化）

- **修复大量会话场景卡顿**：会话索引读写增加缓存与防抖落盘，长会话历史组启用懒渲染（千条以上消息的会话不再整页全量渲染），调试会话卡顿与输入延迟显著改善
- **代码图谱（Graphify）全面提速**：图谱探测全链路异步化，查询/消息路径不再阻塞主线程；探测并发去重、安装/卸载防重入；图谱与当前代码版本不一致时显示「图谱已过期」提示并自动重建；缓存退出前同步落盘，不丢更新

## Bug Fixes（缺陷修复）

- **Local 分支切换误报拦截修复**：工作区仅存在被忽略文件（node_modules/构建产物等）时不再误判为「有未提交改动」阻止分支切换；发送消息时默认跟随仓库真实当前分支，避免旧快照触发意外切换；报错文案带当前/目标分支名与处理建议
- **会话防膨胀修复**：Pi 格式消息中的内嵌超大图片（单条可达 MB 级）现在会被正确识别并剥离，避免会话文件被撑爆、截断逻辑形同虚设
- **修复设置面板返回后左侧栏偶发空白**：从设置返回主界面时左侧栏会话/项目列表出现整块空白的问题已修复（虚拟列表在容器恢复可见时自动重新测量）
- **修复富文本/纯文本模式切换丢草稿**：在富文本与纯文本模式之间切换时，编辑器实例重建可能导致正在进行的草稿同步定时器引用已销毁的编辑器，现已改为持有稳定的 editor 引用并在切换前正确落盘草稿，避免偶发丢字
- **受管浏览器面板精简**：移除浏览器面板中冗余的「Agent 活动」状态行，保留浏览器控制栏与关键操作反馈
