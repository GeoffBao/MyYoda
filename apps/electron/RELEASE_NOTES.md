# MyYoda v0.11.0 更新

## Features（新功能）

- **全新插件中心 v1：总览 / 专家 / 专家团 / 技能 / 连接器 / 记忆**：新增「总览」首页，一键查看已启用插件、待处理连接器、可更新技能与内置能力，附常用入口与推荐连接器；「连接器」页统一聚合 MCP 服务器、API Key 工具与自定义 HTTP 工具，按浏览器 / 媒体 / 搜索 / 我的连接 / 自定义分类展示，卡片直接呈现启用、需配置、依赖缺失、连接失败等状态；连接器详情统一为居中弹层，展示权限、配置方式、能力清单、内置工具列表与最近一次连接测试结果，内置 Chrome 浏览器连接器支持一键检测本机 Chrome 与 Node.js 依赖。旧「MCP / API」入口已全部归一到「连接器」
- **插件作用域选择器**：连接器全局共享、项目可整份覆盖，技能按全局 + 工作区 + 项目三层叠加。插件中心顶部新增作用域选择器，可切换到具体项目查看其覆盖配置，所见与 Agent 实际运行时的生效规则一致
- **通知音效主题库**：设置 → 通用新增 12 套通知音效主题（minimal / soft / glass / arcade / mechanical / organic / dreamy / scifi / rubber / cinematic / studio / zen，CC0 公共领域授权），替换原有 8 个通知音效，按需切换提醒风格

## Improvements（体验改进）

- **长任务进度汇报更及时**：优化 Agent 任务进度更新指引，执行过程中按阶段及时刷新任务状态与当前动作，长任务进展更透明
- **协作子 Agent 默认等待时长延长**：等待子 Agent 完成任务的默认时长从 30 分钟延长到 60 分钟（上限 2 小时不变），长任务不再频繁超时
- **DeepSeek V4 Flash 原生视觉支持**：DeepSeek V4 Flash / Flash Vision Exp 可直接使用视觉能力，无需兜底转换
- **火山方舟（豆包）模型清单修正**：改用套餐授权清单，不再列出订阅套餐未授权的模型
- **飞书支持国际版域名**：飞书集成支持 lark 国际版（larksuite）域名，海外环境可正常接入

## Bug Fixes（缺陷修复）

- **MCP 连接测试结果即时刷新**：编辑抽屉保存后卡片立即同步最新测试结果，无需退出页面重进
- **Agent 提问超时延长**：Agent 向用户提问的等待超时从 2 分钟延长到 15 分钟，长思考场景不再丢失提问
- **长时运行资源泄漏修复**：修复退出清理、任务看板快照、权限与审批请求、飞书/钉钉集成等多处生命周期资源泄漏，长时间挂机内存更稳定
- **渠道协议路由修复**：OpenCode 等渠道按模型目录正确路由协议，修复部分渠道模型能力识别问题

# MyYoda v0.10.16 更新

## Features（新功能）

- **Yoda 插件中心：MCP / Skills 全局与项目双层作用域**：MCP 服务器配置从「按工作区各自隔离」改为「全局共享 + 项目级覆盖」的双层模型，同一套 MCP 配置在所有工作区通用，项目内也可单独覆盖；预置 Skill 统一由全局层提供，不再逐工作区复制，工作区/项目仍可保留自己的同名 Skill（插件中心会标红提示「已被遮蔽」，并给出重命名/删除建议）。首次启动自动完成迁移（幂等可重跑，原配置自动备份可回滚），Skills / MCP 面板按「本项目 / 工作区 / 全局」分组展示

## Improvements（体验改进）

- **通义千问渠道默认协议切回 OpenAI 兼容端点**：新建通义千问渠道时默认走 OpenAI 兼容端点（连接更稳定）；已有的默认 Anthropic 兼容端点渠道会在下次读取配置时自动切换过去，用户自定义了非默认地址的渠道不受影响
- **受管浏览器国内网络优化**：默认新标签页与站内搜索使用 Google，3 秒内未响应会自动改用 Bing，不再长时间空白等待

## Bug Fixes（缺陷修复）

- **规划中心从定时任务编辑页返回后标签错乱**：编辑完定时任务点击返回，之前会被强制跳回 Todo 标签，丢失原本所在的「定时任务」列表位置；现在仅从侧栏直接打开规划中心时才默认落在 Todo，编辑返回会保留原位置
- **受管浏览器放行内网自签名证书**：访问公司内网、自建服务等使用自签名证书或内部 CA 的 HTTPS 站点不再被证书错误拦截（仅在受管浏览器内放行，不影响 MyYoda 主窗口其他连接的证书校验）；地址栏显式指定 443 端口时也会正确按 HTTPS 打开

# MyYoda v0.10.15 更新

## Improvements（体验改进）

- **离屏窗口自动恢复**：窗口被移出屏幕可视范围（如拔掉外接显示器、分辨率变化）后，下次启动会自动把窗口位置拉回可见区域，不再出现"窗口找不到"只能重置配置的情况；测试覆盖窗口生命周期恢复逻辑
- **思考块流式期间自动收起**：Agent 思考内容流式输出时默认折叠为小高度（完成后恢复原有展开阈值逻辑），长思考不再持续撑满对话区域，流式回复期间阅读体验更稳
- **会话迁移更可靠**：会话迁移不再因为短暂的 workspace 不匹配而被拒绝；迁移后会话所属工作区会同步到飞书 Session 镜像，多端归属一致
- **发送消息时状态提示更明确**：会话正在启动、运行中或仍有排队消息时发送，会直接给出明确提示（"请停止或清空队列后再发送"），不再静默失败或等待超时

## Bug Fixes（缺陷修复）

- **切换会话后项目文件面板授权越界报错**：修复切换 Agent 会话后，文件面板短暂使用旧会话授权导致的操作越界报错，切换后文件操作更稳定
- **自适应 Claude 思考档位不再丢失**：修复保存/恢复会话时自适应思考档位被重置的问题，思考档位设置持久保留
- **发送被拒时不再残留"幽灵消息"**：会话忙碌导致发送请求被拒绝时，界面中乐观插入的用户消息会立即回滚，不再残留一条未落盘的假消息直到刷新
- **已删除浏览器会话的状态清理**：后台浏览器会话被回收或删除后，界面上的打开/最小化/待导航状态一并清理，不再出现无法恢复的残留高亮

# MyYoda v0.10.14 更新

## Features（新功能）

- **受管浏览器支持最小化**：浏览器面板新增「最小化」按钮，收起面板但保留页面与登录状态，随时一键恢复；X 按钮仍是真正销毁。后台浏览器会话全局最多保留 8 个，超出时按最久未使用自动回收（绝不回收前台或正在被 Agent 操作的会话），长期多会话使用不再累积内存
- **历史会话未发送内容提醒**：输入到一半未发送的内容现在全链路可见——会话行显示「未发送」徽标、标签页显示圆点，且防抖持久化到本地，重启后仍可找回；「未发送内容找回」区块同步扩展，覆盖其他项目与归档会话（带项目名标签，点击自动切回）
- **项目目录失效可恢复**：会话绑定的项目目录被移动或删除后，不再让整个会话无法启动——报错会提供「重新关联目录 / 设置默认工作区目录 / 关联到候选目录」一键恢复，并自动探测父目录重命名候选（最多 3 个，只建议不自动改）；「默认工作区目录」也正式参与 Agent 工作目录决策

## Improvements（体验改进）

- **GLM-5.3 思考深度档位恢复**：恢复为低 / 高 / 最高三档（强制思考、默认最高），旧会话保存的「关闭思考」会自动映射为低档，不再出现档位缺失或设置丢失
- **上下文压缩完成态优化**：主任务成功交付后的收尾整理上下文阶段，会话状态显示为「已完成」而非一直运行中；运行中的压缩仍保持 running 状态
- **流式回复更流畅**：最终输出更早脱离执行过程区直接展示，思考块流式渲染平滑化，长回复流式期间的布局压力明显降低
- **文件监听降噪**：忽略 Python 虚拟环境与各类测试 / 构建缓存目录（.venv、.pytest_cache、.mypy_cache、.gradle 等）的文件变动，减少无谓刷新与事件风暴

## Bug Fixes（缺陷修复）

- **停止 Agent 更可靠**：运行卡住时停止按钮可重复点击再次发送中断请求；主进程确认运行未按时收敛时会主动关闭卡住的运行时，避免会话永久悬挂
- **压缩后回答耗时不再丢失**：自动压缩发生在最终回答与结果之间时，回答下方的耗时与用量统计现在仍归属该回答，不再神秘消失
- **修复自动任务参数桥接**：部分模型在工具调用中会把可选参数显式物化，导致创建 / 修改定时任务被严格校验拒绝；现在会先丢弃与当前调度模式无关的字段再做校验，创建定时任务更稳定
- **未发送草稿找回区块跨项目修复**：在非会话视图（看板等）也能看到找回入口；跨项目草稿正常展示并带项目名标签；「新会话」智能跳回支持跨项目兜底

# MyYoda v0.10.13 更新

## Features（新功能）

- **兼容无模型列表端点的服务**：部分自建/中转服务不提供 `/models` 接口，现在可在渠道设置中勾选「此服务不提供模型列表端点」跳过拉取，手动添加模型 ID；拉取模型列表遇到 404/405 时也会以友好提示引导手动添加（手动添加的模型不会被后续拉取覆盖）
- **单模型代理开关**：每个模型可独立设置是否走全局代理（添加模型时选「跟随全局代理 / 直连」，已启用模型列表中可随时切换）。适合国内模型直连、海外中转站走代理的混合场景

## Improvements（体验改进）

- **连接测试更贴近真实路径**：OpenAI 兼容渠道的「测试连接」改为用对话端点发最小请求验证（此前用 /models 列表端点，无列表端点的服务会误报）；测试使用渠道中配置的真实模型名，不再用占位名
- **测试连接按模型粒度走代理**：开启全局代理时，配置为「直连」的模型测试连接也直连，验证的就是该模型的真实可达性（此前测试固定走全局代理，直连模型会误报失败）
- **内置渠道无模型也能测试**：OpenAI / 智谱 / 通义 / OpenRouter 等官方渠道补充了真实测试模型，新渠道填完 API Key 即可先测连接再拉模型列表

## Bug Fixes（缺陷修复）

- **修复自定义渠道测试模型名丢失**：自定义地址（OpenAI Chat Completions）渠道已添加模型时，测试连接此前拿不到模型名导致使用占位名被服务端 401 拒绝，现已正确传入用户配置的模型
- **渠道未添加模型时测试提示更明确**：不再发送注定失败的请求，直接提示「尚未配置模型，请先添加模型后再测试连接」

# MyYoda v0.10.12 更新

## Improvements（体验改进）

- **磁盘管理升级为可行动清理面板**：磁盘占用详情展示 Top 10 大文件（含标题/大小/归档状态/更新时间）与孤儿残留数据；归档清理新增「立即清理」按钮（先预览可释放量再确认执行，不必等下次启动）；存量会话中的超大内嵌图片可一键剥离回收空间
- **受管浏览器地址栏支持直接搜索**：`BrowserNavigate` 和浏览器面板地址栏现在可以直接输入搜索词——明确的网址、裸域名、localhost 和 IP 地址仍直达打开，普通文字自动用 Google 搜索；支持导航到 `about:blank` 打开空白页
- **精简渠道命名**：Kimi API 渠道标签简化为「Kimi API」；通义千问渠道合并为单一「通义千问」入口（原 OpenAI 协议旧版渠道仍可正常使用，仅不在新建下拉中展示）
- **火山引擎渠道体系重整**：新增「火山引擎 API」独立渠道；原「豆包」渠道更名为「火山方舟 Coding Plan」，「火山方舟 Coding Plan」（订阅制）更名为「火山方舟 Agent Plan」，配套图标统一替换为火山引擎新版本；存量渠道会自动完成命名迁移，无需手动调整
- **左侧栏功能组恢复纯手动收起**：点击「功能」组内的二级目录（计划/看板/画布/插件/消息/知识库）保持展开并显示全部项（仅高亮激活项），收起只由手动点击「功能」头部触发

## Performance（性能优化）

- **修复大量会话场景卡顿**：会话索引读写增加缓存与防抖落盘，长会话历史组启用懒渲染（千条以上消息的会话不再整页全量渲染），调试会话卡顿与输入延迟显著改善

## Bug Fixes（缺陷修复）

- **Local 分支切换误报拦截修复**：工作区仅存在被忽略文件（node_modules/构建产物等）时不再误判为「有未提交改动」阻止分支切换；发送消息时默认跟随仓库真实当前分支，避免旧快照触发意外切换；报错文案带当前/目标分支名与处理建议
- **会话防膨胀修复**：Pi 格式消息中的内嵌超大图片（单条可达 MB 级）现在会被正确识别并剥离，避免会话文件被撑爆、截断逻辑形同虚设
- **修复设置面板返回后左侧栏偶发空白**：从设置返回主界面时左侧栏会话/项目列表出现整块空白的问题已修复（虚拟列表在容器恢复可见时自动重新测量）
- **修复富文本/纯文本模式切换丢草稿**：在富文本与纯文本模式之间切换时，编辑器实例重建可能导致正在进行的草稿同步定时器引用已销毁的编辑器，现已改为持有稳定的 editor 引用并在切换前正确落盘草稿，避免偶发丢字
- **受管浏览器面板精简**：移除浏览器面板中冗余的「Agent 活动」状态行，保留浏览器控制栏与关键操作反馈
