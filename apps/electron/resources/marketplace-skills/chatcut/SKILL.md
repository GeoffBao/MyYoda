# ChatCut 视频剪辑

ChatCut（chatcut.io）是一个 AI 视频编辑器：告诉它想要什么，它会自动完成剪辑。本技能让 Agent 引导用户完成视频创作与剪辑。

## 能力边界

- 粗剪与精剪：按自然语言描述裁剪片段、调整节奏
- 字幕与包装：自动字幕、样式与转场
- 导出：成片导出（具体格式与分辨率取决于用户账号套餐）

## 使用流程

1. **确认用户意图**：明确视频主题、素材来源（本地上传 / 链接 / 已有项目）、目标时长与风格。
2. **登录检查**：ChatCut 需要账号（网页登录或 OpenAI/ChatGPT 桌面版插件授权）。若用户未登录，引导其打开 chatcut.io 完成登录。
3. **创建任务**：向用户确认任务描述后，把完整的剪辑需求整理成一段清晰的 prompt（素材、剪辑点、节奏、字幕、导出格式）。
4. **执行与反馈**：ChatCut 在云端渲染，向用户说明预计耗时；完成后请用户到 chatcut.io 检查成片，并询问是否需要调整。

## 注意事项

- 本技能是引导型：实际渲染在 ChatCut 云端完成，Agent 不直接持有素材或调用渲染 API。
- 涉及版权/肖像/敏感内容的素材，提醒用户自行确认合规。
- 不承诺具体渲染速度与成功率（受套餐与排队影响）。
