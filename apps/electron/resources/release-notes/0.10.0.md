# MyYoda v0.10.0 更新

## Features（新功能）

### 项目即工作区：统一组织模型

- **项目区全面工作区化**：左侧项目区改为工作区数据源，每个工作区 = 一个项目行（文件夹图标 + 名称 + 本地目录徽标 + 目录状态提示 + 会话树），点击行切换当前工作区；行菜单支持「查看任务 / 重新关联或恢复项目目录 / 删除工作区」
- **新建项目 = 新建工作区**：可选绑定本地工程目录（会话 cwd 与项目记忆落在此目录，名称自动取文件夹名）；留空则创建空白项目（托管目录），创建后自动切换
- **项目页工作区化**：概览 / 会话 / 资料 / 设置四段式；新会话、新任务归属选择器同步工作区化
- **看板融入工作区模型**：卡片显示工作区徽标（跨工作区视图正确归组），TaskEditor 新建任务可选归属工作区，快速任务归属当前工作区
- **项目 → 工作区迁移服务**（设置 → 连接与数据 → 工作区，手动触发）：旧托管项目一键迁移为独立工作区，会话 / 任务 / 定时任务自动重绑定；迁移前自动备份、重名工作区（同名同目录）自动复用
- **项目行交互升级**：点击切换并展开 / 折叠；折叠态自动 peek 当前会话；「显示全部」手动展开完整会话树；项目聚焦跟随右侧会话的持续状态

### 用户反馈直达开发者（提交到 Notion）

- **「更新日志与帮助」新增「意见反馈」入口**：类型支持 Bug 报告 / 功能建议，详细描述最多 5000 字
- **最多 5 张截图**（自动压缩上传，含「截当前窗口」快捷截屏）、联系方式与平台信息
- 设置页「意见反馈」可配置反馈 token 与数据库 ID 并一键「测试连接」；token 经系统安全存储加密，界面永不回显明文
- **提交失败自动降级本地草稿**，杜绝反馈丢失

### 模型渠道

- **火山方舟 Coding Plan 新增 Doubao Seed 2.1 Pro / Turbo**（官方 256K 上下文）
- **消息渠道身份保留**：Agent 消息持久记录来源渠道与模型，跨会话重读不乱

### 代码图谱（Graphify）增强

- **图谱优先强约束**：DeepSeek + Coding 加强 + 图谱就绪时，编码规范自动追加「代码理解优先图谱」条款——理解代码 / 影响面分析优先查图谱而非反复 grep，带三护栏（无果回退 grep、过时/存疑用 Read/Grep 复核、小范围改动豁免）
- **Code Review 图谱优先**：code-review 技能「理解改动」步骤升级为优先图谱工具（邻居 / 最短路径 / 查询图），无图自动退回 CLI explain；编码规范图谱条款触发场景同步覆盖「执行代码审查」

### 补记：DeepSeek 编码能力优化 + Repo Map 代码库地图

> 以下能力随 v0.9.0 已实际发布，但此前更新日志遗漏，本次补记。

- **DeepSeek V4 模型专属编码规范**：deepseek-v4 系列会话自动注入工具调用纪律、先读后改、小步验证、改后必验证、禁止编造 API、影响面清单等约束，补偿 DeepSeek 在编码行为上的短板
- **输出预算提升至 64K**（max_tokens 16384 → 64000），长任务输出不再被截断
- **Coding 模式默认思考深度 max**（会话级选择优先，可在设置关闭）
- **Repo Map 代码库地图自动注入**（Aider tree-sitter 引擎移植，纯本地 AST 分析，支持 C / C++ / C# / Java / Python / TS / Rust / Go 等 10+ 主流语言，带 LRU 缓存防膨胀）
- **4 个预置编码技能**：code-review / ultraqa / deep-interview / ai-slop-cleaner
- **「Coding 加强」总开关**（设置 → 通用）：一键开启上述全部增强，默认关闭，判定逻辑全链路收敛共享

## Bug Fixes（缺陷修复）

- **修复新建项目交互卡顿**：计划模块 EventKit 全量对账与 30s 轮询解耦（降为 5 分钟定期兜底，外部变更仍走 800ms 防抖即时感知），default-skills 拷贝异步化不再阻塞主线程
- **修复本地项目任务无法启动**：任务运行 cwd 兜底补齐 workspace.projectRootPath
- **修复右侧栏项目文件无法查看**：Agent 授权根补上工作区工程目录
- **修复新会话「新建项目」引导误判**（已有项目时仍弹）
- **修复 MiniMap 面板覆盖会话行导致「会话点不开」**（点击穿透）
- **修复项目行聚焦失效**：draft 会话被过滤导致归属永远判空；项目聚焦改为跟随右侧会话的持续状态
- **修复长会话性能退化**（#1627）：消息分页加载 / MCP 空闲回收 / 归档懒加载
- **修复设置页打开时 Agent 流推送竞争**（#1632 降级）
- **修复批量导入 Skill 来源下拉与重复项标注**
- **修复首次点击图谱按钮永久转圈（死锁）**：Graphify 未安装且无图时首次点击会卡在 running 态只能重启，现已正确处理终态；图谱按钮 done 态点击改为增量更新（graphify update），悬停提示同步说明
- **图谱产物自动入 .gitignore**：建图成功后 `graphify-out/` 自动加入仓库 .gitignore，不再污染 git status
- **修复默认技能内容未同步到用户目录**：code-review / graphify 技能版本升级（1.0.0 → 1.1.0），启动同步自动覆盖旧副本，修复仓库内容更新后用户目录仍是旧版（code-review 仍含退役的 CRG 命令等）
- **修复 CI Windows 检查崩溃**：pr-check 的 bun 升级至 1.3.14（与本地开发环境一致）

## Improvements（体验改进）

- **实时表面去除 backdrop-blur**（#1633）：Agent 视图 / 输入容器 / 任务进度层更通透（不透明度 70 → 95），渲染压力更低
- **Graphify 安装日志体验**：长日志不再撑破设置页布局窗口；pip 进度条回车刷新转行渲染，不再累积成超长单行；超长无空格 token（下载 URL / 哈希）强制断行
- **PDF 默认工作流简化**：MarkItDown 优先，skill 精简
- **自动任务组并入项目区并置顶默认折叠**；功能区模块命名统一（去 Yoda 前缀）；恢复左侧「新任务」按钮
- **搜索升级为独立模块**（⌘⇧F 直达 / Esc 返回）：默认态展示最近会话按时间分组，搜索态高亮 + 键盘导航 + Agent 搜索兜底
- **Skills / MCP 统一工作区级**：移除项目级覆盖（与项目 = 工作区模型对齐），切换工作区即切换整套能力
- **任务编辑器展示运行目录预览**，缺失时给出重新关联入口
- **移除 Outbox 与工作区级 .context 概念**（对齐上游，减少概念选择；存量文件保留不迁移）

## Breaking Changes（破坏性变更）

- **项目与工作区概念合并**：原「项目级 Skills / MCP 覆盖」移除，Skills 与 MCP 统一为工作区级；旧托管项目可通过「项目 → 工作区迁移」转为独立工作区
- **Outbox 与工作区级 .context 移除**：会话产出不再有独立的 Outbox 素材索引，交付物直接写入当前执行目录（存量文件保留不删除）
