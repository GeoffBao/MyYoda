# MyYoda v0.7.2 更新

## 新功能

### 专家团重设计：单 Agent 人设包升级为「队友 + Squad 团队」协作

参考 Multica 智能体方案，把原先的「单 Agent 人设包」伪团队方案升级为真实的团队协作：

- **专家升级为队友**：专家人设包新增 `description`、`avatar`（图标 + 主题色）、`defaultProviderChannelId`、`defaultModel`，可在新建 / 编辑时配置，老包零破坏兼容。
- **专家团升级为真实 Squad**：支持 `leader + members + 委派协议`，团长按团队协议编排成员，成员按 role 分工；内置结构校验（leader 不能兼任 member、拦截「团队嵌套团队」）。
- **会话级拉专家 cowork**：对话中可直接拉起一个或多个专家 / 团队协作（CoworkTeamStrip / ExpertCoworkPicker），无需切换会话。
- **新建专家 / 团队 UX 重做**：全新 CreateExpertDialog / CreateTeamDialog，内置通用软件专家等模板。

### 设置新增「用量」Tab：跨会话 Agent 用量统计

- **Overview**：会话 / 消息 / 总 Token / 活跃天数 / 当前连续 / 最长连续 / 高峰时段 / 常用模型 八宫格 + GitHub 风格贡献热力图。
- **Models**：按天按模型堆叠柱状图 + 按模型明细表（表头可排序）。
- **今日用量**：固定展示当天 Token / 消息 / 费用，不随 7d / 30d 档位切换消失。
- 增量聚合缓存：按会话文件指纹复用，避免每次全量扫描；无图表库，纯 CSS 实现，本地优先。

### 其他

- **预置开发方法论 Skills**：内置 default-skills 加入开发方法论类技能。
- **快捷键系统补全**：补全缺失定义并统一渲染。
- **版本历史本地化 + 侧边栏版本号 / 未读红点**。

## 修复

- **worktree 会话编码目录错乱**：新建会话绑定 worktree（新分支）后，`<project_working_directory>` 未随 worktree 联动，Agent 实际改动落在主仓库分支目录；现在 worktree 会话的工程目录与会话工作区隔离目录保持一致，提示词明确指向 worktree 路径。
- **Bash 命令死循环卡死会话**：Bash 工具默认超时注入 + MCP 工具硬超时 + 会话无进展看门狗，防止死循环命令挂死 Agent 会话。
- **dashi-ppt 构建**：浏览器运行时（dist/vendor）纳入 git，修复分发构建。
- **「空间」模块更名「空间容器」**：设置页命名统一。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "MyYoda" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/MyYoda.app
open /Applications/MyYoda.app
```
