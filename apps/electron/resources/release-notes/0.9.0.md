# MyYoda v0.9.0 更新

## Features（新功能）

### 受管浏览器自动化增强

- **Agent 回复链接直达受管浏览器**：Agent 消息中的网页链接直接在应用内受管浏览器打开，风险告知确认后自动跳转（未确认时挂起等待），同一会话连续点击不乱序
- **在系统默认浏览器打开**：浏览器面板新增外链按钮，随时把当前页转到系统默认浏览器
- **支持本机开发服务**：受管浏览器允许 `localhost` / `127.0.0.1` / `::1` / `*.localhost` 导航（自动按 HTTP 打开），本地 HTML/React 开发预览无缝衔接；局域网与私网仍严格隔离
- **WebSearch 不足时回退浏览器**：搜索不可用 / 结果为空 / 质量时效不足时，浏览器成为公开信息检索的备选通道

### 时间窗口型自动任务

- interval 自动任务支持**每日时间窗口 + 周内运行日**组合：一条任务即可表达「工作日 10:00–22:00 每 20 分钟」
- `activeWindowStart` / `activeWindowEnd`（HH:MM，开始包含、结束不包含）+ `activeWeekdays`（0=周日 … 6=周六，空=每天）
- 调度引擎按窗口起点锚定间隔，执行耗时不再造成漂移；窗口外自动跳至下一允许日窗口开始
- 任务列表与日历视图展示「每 X 分钟 · 工作日 · 10:00–22:00」标签；`update_automation` 支持增删窗口与运行日

## Bug Fixes（缺陷修复）

- **浏览器原生视图跨会话隔离**：多个 Agent 会话的受管浏览器不再互相抢占显示槽，晚到的旧布局不会覆盖当前标签（#1569）
- **拒绝无效截图内容**：空图 / 零尺寸 / PNG 数据损坏的截图不再发送给模型；resume 旧会话时历史坏图也会在请求边界被过滤（#1570）
- **浏览器关闭按钮避开 Windows 系统控件**（#1568）
- **修复 Qwen 渠道与浏览器回归**：Qwen 不再使用 developer role；浏览器布局 revision 改用时间戳纪元，主进程重建后新 renderer 不会发布旧序号；更新源 URL 修正（#1574）
- **Skills 列表切换稳定**：开关 Skill 不再触发文件监听导致的列表重排（#1576）
- **输入框焦点不再被抢占**：切换会话 / 流式重建编辑器时不再把用户焦点抢回输入框（#1579）
- **长草稿输入性能**：行数检查改为输入停顿 150ms 后计算，避免长草稿每帧全文扫描（#1579）
- **Scratch Pad 不丢草稿**：退出 / 切走时强制 flush 最后一笔输入（#1579）
- **孤儿数据清理默认关闭**：孤儿目录无法可靠区分用户资料，默认不展示也不删除，避免误删（#1577）
- **Skill 调用 chip 高度对齐**（#1578）

## Improvements（体验改进）

- 侧边栏 streaming 指示器去重：流式文本更新不再触发会话列表按 token 重渲染（#1571）
- 快捷切换提示只更新涉及行，减少强制重排（#1571）
- renderer 性能诊断工具：`?perf=1` 或 `localStorage('myyoda-performance-debug','1')` 启用（#1571）
- 受管浏览器 web search 路由文档更新（#1559）

## Breaking Changes（破坏性变更）

- 磁盘管理中「深度清理 / 孤儿数据清理」功能默认关闭，不再展示孤儿检测 UI（#1577）。删除已归档会话的临时文件仍可用（临时文件清理保留）。
