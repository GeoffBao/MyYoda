# MyYoda v0.7.0 更新

## 品牌升级：LuxCoder 正式更名为 MyYoda

- **全新品牌**：应用名称、界面文案、图标、启动画面、教程、Logo 全面升级为 **MyYoda**。
- **包名统一**：内部包从 `@luxcoder/*` 全面更名 `@myyoda/*`（core / shared / ui / electron / cli / session-core / server）。
- **数据目录迁移**：默认数据目录由 `~/.luxcoder` 迁移到 `~/.myyoda`（开发模式 `~/.luxcoder-dev` → `~/.myyoda-dev`）。
- **仓库与标识**：GitHub 仓库、Release 产物名、Git trailer（Made-with: MyYoda）同步更新。
- **本地数据自动迁移**：首次启动自动完成数据目录迁移，历史会话 / 对话 / 工作区 / 专家 / 技能 / 任务日程全部保留；老用户（`.proma` 时代）也会自动升级到新目录，无需手动复制。迁移采用非破坏策略（原目录保留），并内置误迁移 flag 保护，避免品牌切换时的数据污染。

## 新功能

- **定时任务界面打样**：AutomationsView 列表视图（左侧栏「自动任务」置顶分组跨工作区可见）、空间 / 项目挂载、填入模板（目标/上下文/步骤）、输出模式（创建任务关联项目 / 仅运行）、飞书通知。
- **EventKit 日历双向同步**：连接的外部日历集合可双向同步，Todo / 日程 / 分组 / 标签 / 提醒工具完整接线给 Pi Agent。
- **会话列表折叠预览数量提升**：非活跃会话预览上限由 10 提升到 25，活跃会话不受限，超出部分保留「显示更多」增量展开。

## 修复

- **会话被 draft 标记永久隐藏**：部分已发消息的会话（PlanningView Todo、external run、automation 注入等路径）残留在 draft 集合里被侧边栏过滤隐藏；改为启动时双向对账自愈 + 外部运行完成时兜底移除，历史脏数据自动收敛。
- **SidePanel 项目文件 tab 来源切换按钮消失**：来源 tab bar 独立于 FileSearchBar 渲染，任何情况下始终可切换；「未绑定工作区目录」提示区新增「查看会话文件」按钮。
- **长草稿光标跳动**：修复长文输入时光标跳动问题。
- **git-diff 刷新循环**：修复 watcher 触发无限刷新，并做基线新鲜度保护与节流。
- **EventKit 同步缺陷**：marker 识别 scheme 错配（`proma://` → `myyoda://`）导致受管 locator 认领失效；受管同步目标与外部连接单向互斥补齐对称校验。
- **定时任务创建白屏**：Radix SelectItem 空字符串 value 改非空哨兵值；项目下拉按 slug 归一化匹配并过滤已归档项目。

## 界面与体验

- **Todo 页分割线与边框加重**：提升列表层级可读性。
- 内置技能同步更新：`luxcoder-coach` 更名 `myyoda-coach`，会话清洗 / 技能路由等技能随品牌对齐。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "MyYoda" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/MyYoda.app
open /Applications/MyYoda.app
```
