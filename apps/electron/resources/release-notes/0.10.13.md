# MyYoda v0.10.13 更新

## Features（新功能）

- **兼容无模型列表端点的服务**：部分自建/中转服务不提供 `/models` 接口，现在可在渠道设置中勾选「此服务不提供模型列表端点」跳过拉取，手动添加模型 ID；拉取模型列表遇到 404/405 时也会以友好提示引导手动添加（手动添加的模型不会被后续拉取覆盖）
- **单模型代理开关**：每个模型可独立设置是否走全局代理（添加模型时选「跟随全局代理 / 直连」，已启用模型列表中可随时切换）。适合国内模型直连、海外中转站走代理的混合场景

## Improvements（体验改进）

- **连接测试更贴近真实路径**：OpenAI 兼容渠道的「测试连接」改为用对话端点发最小请求验证（此前用 /models 列表端点，无列表端点的服务会误报）；测试使用渠道中配置的真实模型名，不再用占位名
- **测试连接按模型粒度走代理**：开启全局代理时，配置为「直连」的模型测试连接也直连，验证的就是该模型的真实可达性（此前测试固定走全局代理，直连模型会误报失败）
- **内置渠道无模型也能测试**：OpenAI / 智谱 / 通义 / OpenRouter 等官方渠道补充了真实测试模型，新渠道填完 API Key 即可先测连接再拉模型列表

## Bug Fixes（缺陷修复）

- **修复自定义渠道测试模型名丢失**：自定义地址（OpenAI Chat Completions）渠道已添加模型时，测试连接此前拿不到模型名导致使用占位名被服务端 401 拒绝，现已正确传入用户配置的模型
- **渠道未添加模型时测试提示更明确**：不再发送注定失败的请求，直接提示「尚未配置模型，请先添加模型后再测试连接」
