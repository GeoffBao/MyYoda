# MyYoda v0.10.3 更新

## Improvements（体验改进）

- **置顶会话跨工作区展示**：左侧栏置顶的 Agent 会话不再按当前工作区过滤，切换项目/工作区时置顶区不会跟着变化；来自其他工作区的置顶会话通过归属标签区分，点击后自动切换到对应工作区
- **置顶分组默认展开**：不再默认折叠隐藏置顶会话，折叠按钮改为常驻可见（原来要 hover 才出现），展开全部置顶后列表内部可滚动，不会把下方会话/项目列表挤出可视区域

## Bug Fixes（缺陷修复）

- **修复 Windows 右侧文件面板打开时标题栏按钮错位**：面板打开挤窄中间主区域后，最小化/最大化/关闭按钮的避让宽度不再按 TabBar 自身右边缘硬编码计算，浏览器/终端按钮和标题栏拖拽区域不再被错误地推向面板中间
