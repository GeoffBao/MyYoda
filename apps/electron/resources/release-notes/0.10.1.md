# MyYoda v0.10.1 更新

## Features（新功能）

### Agent 会话内嵌终端

- **TabBar 新增终端按钮**（仅 Agent 会话显示），点击开/关底部终端抽屉
- 基于 node-pty + xterm.js：主进程多终端实例管理（输出滚动缓冲、warmup 预启动、400ms 延迟避免切换 tab 时的 spawn 风暴、10 分钟空闲回收未打开的 pty）
- **主题跟随**：终端背景 / 前景 / 光标跟随应用主题 CSS 变量，宽度自动 fit；支持多 tab 实例栏
- 关闭会话 tab / 应用退出时自动清理 pty；toggle 收起面板保留 pty 供复用

### OpenRouter 余额查询 + 供应商余额区块

- **OpenRouter Key 额度查询**：调用官方 `/api/v1/auth/key`，设置消费上限时展示剩余额度与百分比进度条，未设置上限时展示已用额度并说明限制
- 支持自定义 / 中转域名，兼容 data 包裹与字符串数值响应格式
- **用量统计页新增「供应商余额」区块**：展示所有支持余额查询渠道的 Logo / 名称 / 余额摘要，hover 查看完整明细，支持手动刷新（复用渠道配额缓存层）

### 侧栏交互三项调整

- **会话行 hover 独立归档按钮**（Archive / ArchiveRestore），非归档会话二次点击确认（3s 超时复位），覆盖 Agent 会话与 Chat 对话行
- **Agent 模式新增「已归档会话 (N)」入口**：跨工作区按日期分组的归档视图（含委派子树），切换模式时重置归档状态
- **项目菜单新增「配置 MCP 与 Skills」**：项目三点菜单与右键菜单直达，切换工作区并打开插件视图 MCP tab

## Bug Fixes（缺陷修复）

- **修复新会话 Git / Worktree 上下文栏消失**（v0.10.0 工作区化回归）：仓库路径解析改走 `workspace.projectRootPath`（旧 projectId 链路兜底）；Local / Worktree 改为明确分段控件并补悬停说明；模式记忆键从 projectId 改为仓库路径（修复重构后新会话共用 "undefined" 键、偏好串仓库的问题）；重开空会话回显已绑定 branch / mode 防止误建重复 worktree；分支下拉新增目标仓库头部、占用徽标（排除主 worktree 误标当前分支）与分层警告；仓库判定支持子目录绑定与大小写宽松比较
- **修复会话改绑工作区后终端与侧栏当前项目不同步**：改绑后同步全局当前工作区与持久化设置，左侧栏「当前」高亮正确跟随；pty 复用校验 cwd，变化时杀掉旧 pty 按新目录重建；旧 pty 迟到事件按实例核对隔离，避免误标「已退出」并连锁误杀
- **workspace 化收尾（F3–F6）**：
  - 移除 Teambition 任务认领功能（入口为孤儿组件，用户确认不再需要），看板卡片不再展示同步徽标与重试按钮
  - 新会话不再悄悄绑定存量 projectId（项目上下文由工作区合成上下文接管）；未绑目录的存量工作区保留旧继承兜底，避免会话从项目目录跌回沙箱
  - 移除「移动到项目」菜单，存量项目会话保留「移出项目」单项清理出口
  - 自动化「挂载项目」收敛：工作区绑定工程目录时不再展示存量项目下拉（projectId 不影响 cwd 且会造成 prompt 注入不一致），编辑表单自动归一化清除脏值；未绑目录工作区保留项目选择作 cwd 兜底
  - 看板项目维度只读化：移除归属筛选里的「新建项目」错位入口（新建项目走侧栏 / 设置正规入口），存量项目保留为只读筛选维度
- **代码审查修正**：对 F3/F4/F5 改动做对抗性 review 后修复遗留问题（JSX 缩进错乱、注释文本误改、重复查找收敛为 useMemo 复用）

## Improvements（体验改进）

- **搜索改为居中弹窗**：不再占主内容区（对齐 NewMax），侧栏入口与 ⌘⇧F 统一打开全局 Dialog，Cmd+W / Esc 优先关闭弹窗；默认态增加快捷操作（新建对话 / 新建 Agent 会话），最近会话带工作区信息与快捷键键帽提示
