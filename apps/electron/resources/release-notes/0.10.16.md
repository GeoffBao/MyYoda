# MyYoda v0.10.16 更新

## Features（新功能）

- **Yoda 插件中心：MCP / Skills 全局与项目双层作用域**：MCP 服务器配置从「按工作区各自隔离」改为「全局共享 + 项目级覆盖」的双层模型，同一套 MCP 配置在所有工作区通用，项目内也可单独覆盖；预置 Skill 统一由全局层提供，不再逐工作区复制，工作区/项目仍可保留自己的同名 Skill（插件中心会标红提示「已被遮蔽」，并给出重命名/删除建议）。首次启动自动完成迁移（幂等可重跑，原配置自动备份可回滚），Skills / MCP 面板按「本项目 / 工作区 / 全局」分组展示

## Improvements（体验改进）

- **通义千问渠道默认协议切回 OpenAI 兼容端点**：新建通义千问渠道时默认走 OpenAI 兼容端点（连接更稳定）；已有的默认 Anthropic 兼容端点渠道会在下次读取配置时自动切换过去，用户自定义了非默认地址的渠道不受影响
- **受管浏览器国内网络优化**：默认新标签页与站内搜索使用 Google，3 秒内未响应会自动改用 Bing，不再长时间空白等待

## Bug Fixes（缺陷修复）

- **规划中心从定时任务编辑页返回后标签错乱**：编辑完定时任务点击返回，之前会被强制跳回 Todo 标签，丢失原本所在的「定时任务」列表位置；现在仅从侧栏直接打开规划中心时才默认落在 Todo，编辑返回会保留原位置
- **受管浏览器放行内网自签名证书**：访问公司内网、自建服务等使用自签名证书或内部 CA 的 HTTPS 站点不再被证书错误拦截（仅在受管浏览器内放行，不影响 MyYoda 主窗口其他连接的证书校验）；地址栏显式指定 443 端口时也会正确按 HTTPS 打开
