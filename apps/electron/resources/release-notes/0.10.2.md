# MyYoda v0.10.2 更新

## Features（新功能）

### 发现（Discover）—— 官方内容 + 社区讨论 + 帮助合一

- **左侧栏新增「发现」入口**（与「功能」并列）：官方精选内容流、社区讨论、帮助与反馈四合一面板
- **官方内容流**：视频 / 教程 / 公告 / 外链来自公开内容仓库，带版本号与「更新」红点标记，支持在线流式播放（`discover-video://` 协议、代理感知转发），播放失败可下载后本地播放，磁盘缓存可卡片级删除或一键清理
- **社区讨论**：基于 GitHub Discussions 只读浏览，支持楼中楼评论、被采纳答案标记，无需跳转 GitHub 即可查看详情；发帖/回复跳转浏览器
- **未读逻辑 v2**：侧边栏徽标接入真实未读计数（官方未读 + 社区新回复），公告自动标记已读，讨论支持「新回复」标记
- **离线降级**：网络不可用时缓存优先展示 + 离线横幅，无缓存时给出分级错误态与重试；手动刷新绕过清单内存缓存，内容源更新即时可见
- **帮助分区**：收纳使用指南、FAQ 与键盘快捷键入口；反馈复用 Notion 提交通道
- 图片与头像走本地代理转发（`myyoda-remote://`）并做 token 即时重写，避免跨进程失效

### Agent Runtime 全面升级到 Pi-native 架构

- 引入 `agentEventBus` canonical 事件总线（runId 竞态隔离、endRun scope），Pi-native delta 流替代旧的 adapter/batcher/forwarder 链路
- 渲染层同步升级：`agent-live-transcript-store` + `agent-canonical-stream` 取代旧的 payload→AgentEvent 兼容层
- Pi Runtime 升级到 0.84.2

### 工作区默认目录设置

- 新增应用级设置「默认工作区目录」（`agentDefaultWorkingDirectory`），在设置页「工作区」提供配置入口，替代原来分散在各工作区 config.json 里的旧字段
- 未设置时保留原有 `projectRootPath` 兜底链；设置/清空时自动清理旧字段，避免双源不一致

### 模型与浏览器

- **GLM-5.3 模型预设**：智谱 API 与 Coding Plan 订阅渠道新增 GLM-5.3 并默认启用（GLM-5.2 保持启用，GLM-5.1 维持默认关闭），补齐 1M 上下文等运行时能力
- **浏览器操作跨 Tab 跟随**：Agent 在浏览器中的操作可以跨会话 Tab 实时跟随展示

## Improvements（体验改进）

- **多会话流式渲染优化**：历史消息区改为视口虚拟化挂载（长会话滚动更流畅），发送新消息时保留最近几组消息在普通文档流避免整屏闪烁，prepend 更早历史时按滚动高度差值补偿位置
- **浏览器面板防卡顿**：减少全局 jank，面板打开/关闭改为可中断的过渡动画，切换会话时旧浏览器视图不再短暂闪现
- **会话切换更平滑**：SidePanel / TabContent 组件 memo 化，切换会话只播放内容入场动画，不再整体闪烁
- **工具调用展示改进**：工具调用行新增类型标签与结果摘要（如 Read 返回行数、Bash 完成状态），控件与描述对齐更紧凑
- **富文本输入框焦点保持**：外部草稿同步或可编辑状态切换不再意外抢走输入焦点
- **历史引用 popover 稳定化**：改为 Portal 渲染，鼠标选区用释放位置定位，键盘选区回退到 Range 矩形，避免弹出位置跳动
- 会话滚动条宽度微调；发送消息时防止屏幕闪烁
- KaTeX 中文文本混排数学公式时不再刷屏 Console 兼容性警告

## Bug Fixes（缺陷修复）

- **修复打包版应用打开终端报错 `posix_spawnp failed`**：electron-builder asar 打包后 `node-pty` 的 `spawn-helper` 丢失可执行位，原按 asar 内只读路径 chmod 从未真正生效，现改为对 `app.asar.unpacked` 内真实文件路径授权
- **修复 workspace 化重构后 projectContext 断链**：新会话不再因缺少 `projectId` 而导致 repo_map / graphify 注入静默失效，项目上下文重新对全部新会话生效
- **修复会话标题自动重命名失败**：custom 渠道自动补全 `/chat/completions` 后缀容错官网直接拷贝的 baseUrl；标题生成统一使用 512 tokens 输出预算，避免推理模型把预算耗尽在思考上导致空标题；custom 渠道标题生成失败时同样回退首行兜底重命名
- **修复后台 Tab 消息重复排队**、**Agent Tab 切换延迟**、**Tab 会话内容不同步**等一系列多会话/多 Tab 场景下的状态同步问题
- **修复 thinking 块闪烁**：空流式 turn 期间保留消息 header，避免 thinking 块渲染时机导致的画面跳动
- **修复流式过程中模型身份丢失显示**、**刷新后会话消息不展示**等渲染时序问题
