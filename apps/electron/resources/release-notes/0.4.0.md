# LuxCoder v0.4.0 更新

相对 `v0.3.0`：Code 侧边栏体验重做（折叠交互、紧凑筛选菜单、自定义分组、日期分组折叠）、项目/看板设置简化、多项界面细节修复。

## 新功能

### 侧边栏体验重做
- **紧凑筛选菜单** — 会话列表原「会话｜项目」大 Tab 与底部「已归档会话」按钮，统一收敛为一个筛选菜单（状态 / 分组方式 / 排序方式）。
- **会话自定义分组** — 新增按工作区存储的自定义分组，会话「⋯」/右键菜单可「移动到分组」（新建 / 移动 / 移出）。
- **日期分组新增「前天」+ 折叠交互** — 「今天/昨天/前天/更早」四档分组；鼠标悬浮标题行显示折叠按钮，可收起某一天的会话（对齐 Claude 客户端）；「状态」「自定义分组」分组标题也补上同款折叠按钮。
- **折叠按钮迁移至 TabBar** — 侧边栏折叠/展开按钮移到 TabBar 上，不再随标签横向滚动；折叠态新增 Agent 专家入口。
- **状态点替代强调色条** — 会话行左侧的 3px 状态色条 / 2px 项目色条统一改为行首状态小圆点，视觉更轻；项目行不再显示项目色点（对齐 craft agents）。
- **标题悬浮滚动 + 中段重新生成** — 新增 `MarqueeText` 组件，标题过长时 hover 匀速滚动展示完整内容；标题生成支持挑首/中/尾用户消息 + 最新回复重新生成，参考 craft-agents-oss 补上开场白剥离逻辑，减少带前缀/乱码的标题。

### 项目 / 看板设置简化
- **项目设置弹窗改卡片布局** — 删除自定义 Kanban 列（含 dropStatusId 全链路），长表单堆叠改为分区卡片；MEMORY.md 编辑区新增 token 用量提示，超过注入上限变色警告。
- **下线扫描目录 / 自动发现功能** — 渲染层、preload、IPC 通道、主进程 service 与测试一并移除。
- **工作区默认工作目录** — Agent 技能 → 记忆 Tab 新增设置，未绑定项目的新会话可在 prompt 中获知该目录作为工程代码位置。

## Bug 修复

- **修复「已归档/全部」筛选在日期分组下完全不显示会话** — 状态筛选未正确传导到日期分组数据源，两处门控叠加导致归档会话彻底消失。
- **移除误移植的任务编排横幅** — 原 `AgentTaskPanel` 常驻卡片其实是把 craft-agents-oss 的 playground 演示组件当成了真实产品 UI；改为会话 header 一个「编辑任务」入口，跳转看板打开完整 TaskEditor。
- **悬浮用户消息条改为单行胶囊** — 原「头像+用户名行 + 两行正文 + 附件卡片墙」（~70-90px）会大面积遮挡对话内容，改为单行纯文本摘要胶囊（~30px）。
- **draft 会话持久化丢失** — `bun run dev` 重启 / HMR 后草稿会话状态丢失、空会话重新涌入侧边栏的问题，改为持久化存储 + 启动时自动迁移检测。
- **TabBar 避让 macOS 红绿灯** — 侧边栏折叠后 TabBar 与全屏模式下的窗口控制按钮布局修复。
- **OAuth 登录卡死转圈** — `setup-token` 子进程卡住不返回不退出时加超时兜底，补上此前只有 IPC 没有 UI 入口的取消登录按钮。
- **执行过程吞正文 / 短消息乱换行** — 工具调用之间穿插的文本内容不再被整段吞进折叠的「执行过程」；用户消息气泡不再套用可能导致短消息概率性拆行的排版优化。
- **空态页新增吉祥物** — Chat｜Code 模式切换顺序修正，问候语上方新增 OpenMoji 机器人插画。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "LuxCoder" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/LuxCoder.app
open /Applications/LuxCoder.app
```
