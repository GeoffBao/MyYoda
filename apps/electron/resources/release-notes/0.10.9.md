# MyYoda v0.10.9 更新

## Improvements（体验改进）

- **用量统计对齐 DeepSeek 官方口径**：总 Token 改为「输入（含缓存命中 + 未命中）+ 输出」，与 DeepSeek 平台「Token 用量」展示一致，方便对账；模型明细表按「输入 · 缓存命中 / 输入 · 缓存未命中 / 输出」三列展示，与 DeepSeek 官网定价页结构一致。费用始终按渠道返回的实际扣费金额统计，不受口径影响

## Bug Fixes（缺陷修复）

- **消息队列窗口重开后恢复派发**：主进程重启或窗口重开后，之前搁置的排队消息能继续正常派发，渲染端队列展示也会在重载后自动重建
