# MyYoda v0.10.11 更新

## Performance（性能优化）

- **修复长会话累积卡顿**：长时间运行后输入延迟、会话切换和历史滚动持续变卡的问题已修复——流式 delta 改整批应用、消息落盘改批量写入、后台会话结束即回收运行态、高频事件改按会话直读，运行再久也不累积开销
- **索引读写提速**：会话索引增加内存缓存与防抖合并落盘，大量会话下键盘与主进程不再被反复解析索引阻塞

## Improvements（体验改进）

- **侧面板开关按会话记忆**：文件面板的展开/折叠状态现在每个会话独立保存，切换会话不再互相覆盖；删除会话会一并清理对应状态
- **新增 BrowserClose 能力**：Agent 需要结束整个浏览器会话时，可调用 BrowserClose 关闭受管浏览器及其全部标签（保持用户对浏览器的控制）
- **存量渠道自动补入 GLM-5.3 候选**：方舟 Coding Plan、豆包、智谱等渠道一次性补入 GLM-5.3 候选模型（默认禁用，需要时手动启用，已删除的模型不会被重复补回）
- **渠道配置原子写入**：渠道配置改用临时文件 + 原子替换写入，降低异常断电导致配置损坏的概率

## Bug Fixes（缺陷修复）

- **语音输入重复点击拦截**：听写停止/提交尚未完成时再次点击会被忽略，避免旧语音会话与新会话交叉；取消或提交后按钮状态复位时机修正，不再出现点击被旧会话吞掉
- **流式输出跟随恢复**：Agent 回复过程中自动滚动跟随恢复正常，运行计时器与可见内容对齐，空 assistant 快照不再与计时器重复显示消息头
