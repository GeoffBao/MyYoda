# MyYoda v0.7.5 更新

## 回退

### Pull Request 完整闭环功能回退

v0.7.4 引入的 PR 工作流（创建 / 查看 / 合并 / 评论 + 独立 Tab + 左栏 Pull Requests 列表）整体回退至未引入状态：相关 UI 入口、PR 独立 Tab 与本地 gh CLI 数据通路一并移除，恢复引入前的行为。

### 本地 Skill 上传社区市场 + 用量统计回退

v0.7.4 引入的「一键上传本地 Skill 到社区市场」与「Skill 用量统计」整体回退：Skill 卡片 / 详情面板不再展示用量徽标，社区市场上传入口移除。

## 新功能

### 上下文压缩按钮二次确认

手动压缩按钮由单击触发改为**点击两次确认**：第一次点击进入确认态（按钮变警示色，提示「再次点击确认压缩」），再次点击才真正触发；3 秒无操作或弹层关闭时自动重置，避免误触导致上下文被意外压缩。

## 修复

- **引用历史后自动聚焦输入框**：将历史片段添加到 Agent 引用后，输入框自动获得焦点，可立即继续输入（#1494）。
- **getFileDiff 修复**：preload 层 `getFileDiff` 漏写 `return` 导致调用方永远拿到 `undefined` 的问题修复。
- **git-diff 性能优化**：仓库扫描结果做一致性缓存，减少重复扫描，提升代码改动视图加载速度（#1480）。

> 如果打开应用时提示：
>
> > "MyYoda" is damaged and can't be opened.
>
> **这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/MyYoda.app
open /Applications/MyYoda.app
```
