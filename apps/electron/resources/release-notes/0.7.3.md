# MyYoda v0.7.3 更新

## 新功能

### Yoda 插件 / Yoda 记忆迁回左侧栏独立视图

撤销 8 月初「设置面板收纳」决策，两个功能重新做成左侧栏独立入口，无需再进设置：

- **Yoda 插件**（专家 / Skills / MCP / API）与 **Yoda 记忆**恢复为左侧栏独立视图，一处直达；原设置面板里的对应 Tab 已移除。
- **Excalidraw 画布改名 Yoda 画布**，位置紧邻 Project 看板下方。
- **拉专家 / 专家团入口去重**：删除会话标题栏中与输入框重复的按钮，输入框工具栏最左侧保留唯一入口，不再因上下文用量徽标显隐而位置跳动。

### 工作区记忆右侧栏实时 Dock + 独立记忆窗口

对齐最新上游架构，工作区记忆维护从「运行后弹窗提示」升级为实时协作：

- 主进程实时监听 `memory/` 目录变化，右侧栏常驻 Dock 悬浮展示真实文本 diff，改动即刻可见。
- 一键打开独立记忆编辑窗口，支持保存 / 未保存关闭确认。
- 记忆写入门槛放宽：明确、稳定、不冲突的最小增量可直接写入并事后说明，仅删除 / 大段覆盖 / 冲突 / 不确定推断 / 敏感信息才需确认。

### FAQ 与使用指南增强

- 新增 **FAQ 对话框**：内置 Agent / Skills / 项目 / 记忆 / 自动化 / 用量等常见问题图文说明，侧边栏「?」与设置入口均可打开。
- **使用指南增强**：新增学习路径与图片灯箱，新手上手更直观。

### 插件市场默认来源切换

- 插件市场默认来源切换为 **MyYoda 私有市场**（GeoffBao/myyoda-skills），内置技能更可控、更新更及时。

## 修复

- **后台 Agent 排队消息不发送**：主窗口禁用后台节流（backgroundThrottling），窗口被遮挡或最小化时 Chromium 不再降速，排队消息能正常发出。
- **worktree 占用分支选择歧义**：Local 模式下点选被其他 worktree 检出的分支不再置灰，点击自动切到 worktree 模式并选中，副标题同步提示「已被占用 · 将切 worktree」。
- **diff 状态标记统一**：未跟踪文件列表改用统一的 GitStatusMarker（untracked）展示，替代硬编码「新建」橙色标签。
- **应用内版本历史回退**：修复 release note 归档目录错位导致版本历史停留在旧版的问题，并新增发布流程门禁——tag 版本缺少对应应用内 release note 时构建直接失败。

## macOS 打开说明（重要）

当前 Release **未配置 Apple Developer ID 签名/公证**。从浏览器下载后，macOS Gatekeeper 可能误报：

> "MyYoda" is damaged and can't be opened.

**这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/MyYoda.app
open /Applications/MyYoda.app
```
