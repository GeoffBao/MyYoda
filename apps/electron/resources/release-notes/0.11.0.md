# MyYoda v0.11.0 更新

## Features（新功能）

- **全新插件中心 v1：总览 / 专家 / 专家团 / 技能 / 连接器 / 记忆**：新增「总览」首页，一键查看已启用插件、待处理连接器、可更新技能与内置能力，附常用入口与推荐连接器；「连接器」页统一聚合 MCP 服务器、API Key 工具与自定义 HTTP 工具，按浏览器 / 媒体 / 搜索 / 我的连接 / 自定义分类展示，卡片直接呈现启用、需配置、依赖缺失、连接失败等状态；连接器详情统一为居中弹层，展示权限、配置方式、能力清单、内置工具列表与最近一次连接测试结果，内置 Chrome 浏览器连接器支持一键检测本机 Chrome 与 Node.js 依赖。旧「MCP / API」入口已全部归一到「连接器」
- **插件作用域选择器**：连接器全局共享、项目可整份覆盖，技能按全局 + 工作区 + 项目三层叠加。插件中心顶部新增作用域选择器，可切换到具体项目查看其覆盖配置，所见与 Agent 实际运行时的生效规则一致
- **通知音效主题库**：设置 → 通用新增 12 套通知音效主题（minimal / soft / glass / arcade / mechanical / organic / dreamy / scifi / rubber / cinematic / studio / zen，CC0 公共领域授权），替换原有 8 个通知音效，按需切换提醒风格

## Improvements（体验改进）

- **长任务进度汇报更及时**：优化 Agent 任务进度更新指引，执行过程中按阶段及时刷新任务状态与当前动作，长任务进展更透明
- **协作子 Agent 默认等待时长延长**：等待子 Agent 完成任务的默认时长从 30 分钟延长到 60 分钟（上限 2 小时不变），长任务不再频繁超时
- **DeepSeek V4 Flash 原生视觉支持**：DeepSeek V4 Flash / Flash Vision Exp 可直接使用视觉能力，无需兜底转换
- **火山方舟（豆包）模型清单修正**：改用套餐授权清单，不再列出订阅套餐未授权的模型
- **飞书支持国际版域名**：飞书集成支持 lark 国际版（larksuite）域名，海外环境可正常接入

## Bug Fixes（缺陷修复）

- **MCP 连接测试结果即时刷新**：编辑抽屉保存后卡片立即同步最新测试结果，无需退出页面重进
- **Agent 提问超时延长**：Agent 向用户提问的等待超时从 2 分钟延长到 15 分钟，长思考场景不再丢失提问
- **长时运行资源泄漏修复**：修复退出清理、任务看板快照、权限与审批请求、飞书/钉钉集成等多处生命周期资源泄漏，长时间挂机内存更稳定
- **渠道协议路由修复**：OpenCode 等渠道按模型目录正确路由协议，修复部分渠道模型能力识别问题
