# MyYoda v0.10.7 更新

## Features（新功能）

- **「发现」入口常驻侧边栏**：左侧栏「发现」移到「搜索」与「功能」之间，Chat 与 Agent 两种模式均显示，官方精选、社区讨论与意见反馈随时可达
- **「功能」组智能折叠**：点开「功能」选择计划 / 看板 / 画布 / 插件 / 知识库后，功能组自动只保留当前激活项（其余隐藏）；点开未选择时点击侧边栏其他区域自动整体收起，保持侧边栏清爽

## Improvements（体验改进）

- **Agent 长会话更流畅**：会话记录与侧边栏活跃列表虚拟化渲染，配合 Pi 原生增量输出，长会话下输入与历史渲染卡顿明显缓解
- **侧边栏保持 MyYoda 特有设计**：恢复 active-list 会话列表设计、Heptabase 风格文件夹图标与「当前」徽标，上游同步不覆盖 MyYoda 侧栏设计

## Bug Fixes（缺陷修复）

- **修复侧栏置顶图标不可见**：置顶会话的 pin 图标在部分状态下不显示的问题已修复
- **修复跨渠道模型信息丢失**：同名模型在不同渠道的展示信息不再丢失
- **修复标题生成失败无兜底**：custom / OpenCode Go 渠道标题生成失败时统一回退兜底重命名

## 其他

- 同步 upstream 基线至 f003185fe（v0.17.26 baseline + Pi runtime 隔离收尾 + 侧栏虚拟化）
