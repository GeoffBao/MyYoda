# MyYoda v0.10.5 更新

## Bug Fixes（缺陷修复）

- **修复「发现－官方精选」视频播放失败**：视频流式播放/下载此前只走 Node 全局 `fetch`（未在 MyYoda「代理配置」页显式开启代理时不会读取系统 HTTP 代理/VPN），而该设置页明确标注是给 AI API 请求用的，多数用户不会为了看官方视频专门去开；GitHub Release 视频资源又没有 CDN 镜像兜底，导致系统层有代理/VPN 但未在 MyYoda 里配置的用户视频完全无法播放。现在主进程请求失败时自动用 `net.fetch`（Electron/Chromium 网络栈，自动感知系统代理）重试兜底，不依赖用户额外配置
- **会话头部 Git 分支徽章漂移自愈**：会话头部 `Local · <branch>` 徽章此前读取的是持久化字段，仅通过 UI 分支选择器操作时才写入；Agent 直接执行 `git checkout` 等命令切换分支后徽章永久卡在旧值，刷新或重进会话都无法自愈。现在会话挂载和窗口重新聚焦时会静默核对仓库当前实际分支，检测到漂移直接回写（仅 Local 模式，Worktree 专属绑定分支不处理）
- **修复空回复保护漏检「有活动无最终结论」场景**：模型多轮工具调用后最后一条消息只有 thinking、没有任何文字就停止时，此前既有的空回复保护不会触发，用户看到一堆工具调用后戛然而止且无任何错误提示。现在会从最后一条 assistant 消息倒序判断本轮真正终止时是否给出非空文字结论（thinking 不算数），命中时进入失败态并给出重试/切换模型按钮，按是否有工具活动区分提示文案
- **置顶会话始终显示所属工作区名**：置顶区原本只在会话属于非当前工作区时才渲染工作区名标签，当前项目（如 synara）的置顶会话不显示项目名，与普通项目分组列表行为不一致；现在只要有工作区就显示标签
- **会话行悬浮操作按钮不再遮挡标签**：悬浮操作按钮进入文档流布局，彻底避免盖住「3/3」等标签，并优化会话行工作区名截断与操作按钮重叠
- **双击「发现」不再误展开「功能」模块组**：修复双击「发现」图标误触发展开/折叠「功能」模块组的问题
