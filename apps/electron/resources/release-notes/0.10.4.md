# MyYoda v0.10.4 更新

## Performance（性能优化）

- **流式输出渲染大幅降载**：助手流式回复不再每帧对全文重跑 Markdown 解析管线，改为按顶层 block 分块记忆化渲染，只有正在增长的尾段重新解析；代码块高亮与语言自动检测增加 LRU 缓存，流式期间跳过昂贵的语言推断（流结束后补跑一次），长回复、大代码块场景下输入、滚动和侧边栏不再卡顿
- **历史列表常驻开销降低**：项目分组的隐藏历史会话列表在收起动画结束后卸载，不再常驻占用渲染与监听开销

## Improvements（体验改进）

- **历史展开/收起动画**：侧边栏项目分组的历史会话列表收起与展开带平滑过渡
- **切换会话进入过渡**：切换 Agent 会话标签时，新内容带短暂淡入过渡，减少切换时的生硬跳变
