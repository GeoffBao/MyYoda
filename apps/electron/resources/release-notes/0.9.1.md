# MyYoda v0.9.1 更新

## Features（新功能）

### Yoda 插件按 Project 隔离能力

- **Skills / MCP 项目级覆盖**：Skills 与 MCP 现在可以为单个 Project 单独配置；未单独配置时自动回退到「全部项目共享」的工作区级能力，现有项目零回归
- **跨 Project 批量导入 Skill**：同一工作区内其他 Project（含「全部项目共享」）可作为来源批量导入 Skill，重复项自动跳过
- **Memory 并入 Yoda 插件**：左侧栏独立的「Yoda 记忆」入口并入 Yoda 插件为第 6 个 tab，对齐两段式记忆引导（建立工作区地图与协作画像 / 授权会话补证据），原有一键生成记忆保留为快捷入口
- **Project 设置页能力入口**：设置页新增 Skills / MCP 摘要（数量 + 是否已单独配置），一键「管理 →」跳到 Yoda 插件并预选中该 Project

### 受管浏览器

- **导航目标放宽**：受管浏览器不再限制导航目标网络与协议，任意可解析的 URL 均可导航（仍保留下载、弹窗与权限拦截）（#1605）
- **真实弹窗与静默下载**：`window.open` 用系统窗口承接真实弹窗；下载经安全校验后静默落到系统下载目录，并对弹窗 / 下载恢复公网 + loopback 与 DNS 私网防护（#1616）

### 搜索与渠道

- **模式隔离模糊搜索**：全局搜索按会话类型（Chat / Agent）隔离搜索范围，结果匹配与排序优化（#1586）
- **新增 Qwen3.7 Flash 渠道预设**（#1617）

## Bug Fixes（缺陷修复）

- **修复全局搜索在草稿本 / Work 模式下失效**：MyYoda 比上游多出 cowork / scratch 两种模式，上游「模式二选一」逻辑会让这两种模式下搜索短路为空，已回退为同时搜索 Chat + Agent（改动前行为）
- **语音听写就绪修复**：等待麦克风真正捕获到音频再进入就绪，不再因首个回调延迟停在「准备麦克风」（#1590 / #1603）；麦克风权限后正确恢复音频上下文（#1614）
- **压缩前过程组消息自动折叠**：上下文压缩前产生的过程消息不再在实时视图里滞留（#1607 / #1615）
- **后台队列消息自动派发**：窗口在后台时队列消息仍能正确派发（#1594）
- **修复 Windows Ctrl+B 快捷键冲突**：侧边栏折叠按钮的快捷键提示与行为对齐（#1593）
- **富文本编辑保留 Mermaid 预览**（#1595）；**修复标签式加粗标记渲染**（#1598）
- **忽略浏览器陈旧标签导航事件**（#1592）；**导航键携带键码触发默认滚动**（#1597）
- **自动化调度字段规范化与校验**：更新调度时非法字段组合被规范化 / 拒绝，避免产生无法解析的调度（#1610 / #1612）
- **OpenCode Go Vision Relay 模型路由修复**（#1609）；**日历视图正确渲染自动化时间窗口**（#1608）
- **修复仅查看 Project 的 Skills 标签页就会在代码仓库创建空 `.context/skills/`** 的问题
- **修复切换 Project 时设置页能力摘要闪现上一个 Project 旧数据** 的问题

## Improvements（体验改进）

- **输入框与历史渲染隔离**：高频 token / 实时状态订阅限制在历史区域内，输入框与工具栏不再随流式输出重渲染（#1613）
- **历史选区引用优化**：选区计算只更新涉及行，减少强制重排（#1618）
- **后台流事件节流与批处理**：主进程按前台 / 后台节流 partial，渲染进程每帧批处理，降低后台流开销（#1620）
- **移除历史滚动逐帧扫描**（#1600）；**降低输入渲染抖动**（#1591）；**移除队列消息 toast**（#1582）
- **侧边栏自动任务组默认折叠**：最多显示 4 个，超出折叠为「显示更多」，对齐置顶区交互
- **范围切换器分层澄清**：明确区分「选范围（全部项目共享 / 具体 Project）」与「切换工作区」，避免同名倒序造成混淆
- **Skills 空态可操作**：空状态增加可点击的导入入口
- **使用指南与 FAQ 全面同步**：修正过时访问路径与文件路径，补充 Project 范围能力说明
- **新增 `dist:mac` 打包脚本**（#1604）
