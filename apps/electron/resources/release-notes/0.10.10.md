# MyYoda v0.10.10 更新

## Improvements（体验改进）

- **流式输出更平滑**：流式渲染性能优化，逐字输出不再卡顿，长会话滚动更跟手
- **会话切换过渡更自然**：切换会话加入淡入/平滑过渡，旧浏览器视图及时隐藏，避免闪现
- **输入框编辑更顺手**：编辑历史消息时保持输入焦点，不再被重渲染打断
- **对话滚动条微调**：滚动条宽度调整，视觉更协调
- **浏览器面板更流畅**：全局卡顿优化，浏览器面板切换平滑过渡

## Bug Fixes（缺陷修复）

- **排队消息状态更稳定**：消息 uuid 对齐，预检期间停止派发不再出现竞态；重开后保留排队消息运行状态
- **等待用户回答更可靠**：收到提问后等待回答完成再执行后续工具，避免提前抢跑
- **GLM-5.3 推理兼容性修复**：修正 reasoning profile 路由，GLM-5.3 使用更稳定
- **受管浏览器放开私网导航与下载限制**：支持访问私网地址与下载文件
- **历史消息引用弹层定位稳定化**：长会话中引用弹层不再错位
- **图谱按钮状态修正**：窗口聚焦时主动重查真实状态，不再残留 running
- **自动重试不再泄漏子进程**：修复自动重试路径泄漏 utility runtime 子进程的问题

## 其他

- 事件品牌标识统一为 myyoda_event
- 内部：补回 upstream #1663–#1674 回归修复，新增 GLM-5.3 reasoning profile 回归测试锁定
