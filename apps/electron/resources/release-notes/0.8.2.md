# MyYoda v0.8.2 更新

## Bug Fixes（缺陷修复）

### Repo Map 稳定性修复（#48）

依据产品实测报告修复 Repo Map 的三个问题：

**1. 缓存并发损坏自愈**
- 修复多实例/多 worktree 并发写缓存导致 JSON 损坏（30MB 缓存含非法转义、文件被清空）
- 唯一临时文件（pid+时间戳）+ 进程写锁 + 读-合并-写：并发写不损坏、不丢条目
- 损坏缓存自动备份（保留现场便于排查）并重建；异常退出残留锁自动清理

**2. CDN 离线可用（符号索引为空问题）**
- 内置 10 种常用语言解析器（ts/tsx/js/python/go/java/c/cpp/rust/php）：离线开箱可用
- 多源回退（unpkg → jsdelivr → fastly）+ 24h 失败冷却 + 超时保护 + 文件校验
- dart 解析器实测与内置运行时 ABI 不兼容，未内置（可手动放置兼容版本）

**3. 多 worktree 会话卡顿（重复全量扫描）**
- 代码地图改为按**主仓库 main 分支**共享：所有 worktree/本地分支共用一份地图，
  本地 commit/push 不再触发重新扫描
- main 同步新代码时：旧地图继续使用 + 后台增量重扫（不阻塞对话）
- 地图盘上缓存跨进程共享，重新打开秒回；首条消息前后台预热（warmUp）

### CRG 共享图谱（#48）

- worktree 会话使用 code_review_graph 时引导使用主仓库路径建图/引用，
  避免每个 worktree 重复构建全量知识图谱（省空间 + 首次不卡）
- 分支差异分析用 `detect_changes(base=main)`，增量索引用 `update`

## Improvements（体验改进）

- 地图质量：排除 default-skills/测试文件等噪声目录，核心源码符号排名靠前
- 主进程性能：git 调用与目录扫描增加短缓存，降低每条消息的同步阻塞

## Breaking Changes（破坏性变更）

无。
