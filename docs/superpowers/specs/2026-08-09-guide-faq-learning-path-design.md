# Guide 与 FAQ 学习路径设计

## 目标

让第一次使用 MyYoda 的用户能够完成一条真实工作流，而不是只看到功能展示；同时让 FAQ 成为可检索的问题库，并让所有产品截图都能被放大阅读。

## 设计决策

### 使用指南：从功能展览改为学习路径

使用指南保留现有编辑风格，但增加明确的章节导航和可执行内容：

1. 配置模型渠道
2. 创建 Workspace / Project
3. 创建 Agent 会话
4. 写清楚任务目标、范围、限制和验收标准
5. 组织会话文件、Project 文件与记忆
6. 使用 Skills / MCP / 专家
7. 创建 Task 与自动任务
8. 常见失败排查

每个核心章节包含用途、步骤、真实示例和下一步建议。旧教程中的 Proma 专属内容、过时界面和旧视频链接不迁移。

### FAQ：从概念问答扩充为问题库

保留“左侧主题目录 + 右侧问题列表 + 搜索”的交互，补充 Chat/Code 选择、目录组织、提示词、会话拆分、记忆、工具权限、任务失败与模型故障等高频问题。FAQ 不承载长篇观点和完整教程。

### 图片：统一大图预览

Guide 与 FAQ 的图片卡片统一使用轻量 Lightbox：点击图片打开居中的大图，显示标题和说明；支持背景点击、关闭按钮和 Escape 关闭；缩略图保留 hover 提示，不改变原素材文件。

### 视频

保留“视频教程即将上线”占位，不继续展示旧链接。未来重新录制后只替换视频区域。

## 验收标准

- 用户能从使用指南目录跳到任意章节，并完成第一次 Agent 工作流。
- Guide 和 FAQ 中的每张截图都能点击放大，且可用 Escape 或背景关闭。
- FAQ 至少覆盖 8 个实用主题，新增问题不依赖 Proma 专属功能。
- 现有设置左侧入口、主界面帮助入口和 FAQ 入口继续可用。
- 类型检查、相关测试和 Renderer 构建通过。
